# Сайт Ангелины Глуховой

Статический сайт психолога на Astro. Текущая версия – технический и UX-каркас с черновым контентом.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:4321`.

## Перед публикацией

1. Перед продакшен-сборкой задайте переменную окружения `SITE_URL` с реальным доменом. Без неё используется текущий адрес сайта на Tilda.
2. Заменить Telegram и WhatsApp во всех CTA.
3. Добавить финальные фотографии и при необходимости заменить стандартное Open Graph изображение.
4. Проверить цены, адрес, квалификации и правила отмены.
5. Подготовить юридическую политику конфиденциальности.
6. Выполнить `npm run build`.

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: 22

Для статического режима адаптер Cloudflare не нужен.
