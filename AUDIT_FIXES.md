# Критический аудит и исправления

## Исправлено

- Удалена незаполненная страница политики конфиденциальности.
- Удалена ссылка на политику из футера: сайт не собирает данные и не содержит форм/аналитики.
- Исправлен лишний прижим пагинации статей к футеру: добавлен нижний отступ.
- Сокращена избыточная высота hero-блока статьи.
- Добавлена поддержка даты обновления статьи через `updatedAt`.
- Добавлена структурированная разметка Schema.org для автора и статей.
- Исправлено стандартное Open Graph изображение: теперь используется существующий файл.
- Добавлен favicon.
- Убран отсутствующий постер видео, чтобы сайт не делал запрос к несуществующему файлу. Его можно вернуть после подготовки изображения.
- `robots.txt` теперь генерируется автоматически из адреса сайта.
- Адрес сайта задаётся переменной окружения `SITE_URL`; без неё используется текущий адрес на Tilda.
- Трек видео приведён к типу `subtitles`.

## Перед публикацией на новом домене

Задайте переменную окружения:

```bash
SITE_URL=https://ваш-домен.ru
```

После подготовки постера верните в `src/pages/index.astro`:

```astro
poster="/images/video-poster.webp"
```

и положите файл в:

```text
public/images/video-poster.webp
```
