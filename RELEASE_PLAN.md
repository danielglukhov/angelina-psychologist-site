## Публикация

1. Создать репозиторий GitHub.
2. Загрузить проект без `node_modules`, `.astro` и `dist`.
3. Подключить Cloudflare Pages.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Добавить переменную `SITE_URL=https://ваш-домен`.
7. Подключить домен.
8. Настроить единственный основной вариант: с `www` или без `www`.
9. Проверить HTTPS и редиректы.
