# Psyway Design System

Небольшая дизайн-система сайта частной психологической практики.

## Принципы

- Спокойствие вместо визуального шума.
- Человеческий язык вместо медицинского официоза.
- Один основной акцентный цвет.
- Крупная типографика и свободный вертикальный ритм.
- Компоненты создаются только для повторяющихся задач.

## Архитектура стилей

- `src/styles/tokens.css` – цвета, типографика, интервалы, радиусы, тени и layout-токены.
- `src/styles/reset.css` – базовый reset браузера.
- `src/styles/global.css` – глобальная типографика, кнопки, карточки и utilities.
- Локальные `<style>` внутри компонентов – только специфичная композиция компонента.

## UI primitives

- `Container` – ограничение ширины контента.
- `Section` – вертикальный ритм секций.
- `SectionHeader` – eyebrow, заголовок и описание секции.
- `Button` – primary и ghost.
- `Card` – базовая поверхность контента.
- `CTA` – финальный блок действия.

## Page blocks

- `Hero`
- `Requests`
- `About`
- `Video`
- `Services`
- `FAQ`
- `ContactCTA`

Главная страница только собирает блоки и не содержит локальной бизнес-разметки.

## Breakpoints

Компоненты переходят в одну колонку преимущественно около `50–56rem`. Мобильная навигация включается до `62rem`.

## Цветовые роли

Используйте семантические токены, а не hex-значения внутри компонентов:

- `--color-background`
- `--color-surface`
- `--color-surface-muted`
- `--color-text-primary`
- `--color-text-secondary`
- `--color-border`
- `--color-accent`

## Изображения

Публичные изображения находятся в `public/images/` и используются через абсолютные пути вида `/images/hero.png`.
